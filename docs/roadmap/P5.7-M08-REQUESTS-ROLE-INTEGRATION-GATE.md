## 1. Objectives & Scope Delivered

1. **Terminology Standardization ("Solicitudes" / "Solicitudes pendientes")**:
   - Audited and updated i18n keys in `src/lib/i18n.ts`:
     - Spanish: `approvalInbox.errorTitle` changed from "No se pudieron cargar las aprobaciones" to "No se pudieron cargar las solicitudes".
     - English: `approvalInbox.errorTitle` changed from "Approvals could not be loaded" to "Requests could not be loaded".
     - Added `selfApprovalForbidden` in Spanish ("No puedes aprobar o rechazar tus propias solicitudes") and English ("You cannot approve or reject your own requests").
   - Verified that manager and employee navigation items strictly use "Solicitudes" (never "Aprobaciones").

2. **Pending Requests Counter in Sidebar & Topbar**:
   - Added `pendingRequestsCount?: number` to `AppShellProps` in `src/components/app-shell/AppShell.tsx`.
   - In sidebar: `sidebar-approvals` displays numeric badge when `pendingRequestsCount > 0`.
   - In topbar: added responsive pending requests counter button (`data-testid="topbar-pending-requests"`) displaying count and triggering requests inbox.
   - Polled/updated `pendingApprovalsCount` in `src/App.tsx` during `refreshCalendarData` for managers (OWNER/ADMIN/PLANNER).
   - Styled topbar badge in `src/components/app-shell/AppShell.css` with light and dark mode parity.

3. **Anti-Self-Approval Rule Enforcement**:
   - **Backend**:
     - `POST /api/approval-requests/:id/approve` and `POST /api/approval-requests/:id/reject` enforce 403 `self_approval_forbidden` when `existingRows[0].employee_user_id === ctx.user.id || (ctx.employeeId && existingRows[0].employee_id === ctx.employeeId)`.
     - `GET /api/approval-requests` query excludes self-requests from approver inbox.
   - **Frontend UI (`src/components/shift-dashboard/ApprovalInbox.tsx`)**:
     - Accepts `currentEmployeeId` and `currentUserId` props from `ApprovalInboxModal` and `App.tsx`.
     - Renders an informative amber warning banner (`data-testid="self-approval-warning-${request.id}"`): "No puedes aprobar o rechazar tus propias solicitudes" when request is submitted by the caller.
     - Disables "Aprobar" and "Rechazar" action buttons when `isSelfRequest` is true.
     - Gracefully catches server 403 / `self_approval_forbidden` error responses on approve/reject and displays the localized explanation in the alert container.
     - Added warning styling in `src/index.css` with dark mode support.

4. **Employee Requests View**:
   - Maintained employee change request workflow (`RequestStatus`, `NewChangeRequestModal`) accessible via `sidebar-requests` in the employee portal.
