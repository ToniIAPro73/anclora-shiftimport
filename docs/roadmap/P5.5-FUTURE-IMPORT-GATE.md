**Estado**: `PASS`

**HEAD de evidencia**: `2327e3e` (implementación funcional P5.5)

## Resultado

P5.5 separa la fecha operativa con el helper común `Europe/Madrid`: `date < today` se persiste como
`Shift` histórico y `date >= today` se enruta a `ScheduleVersion` `DRAFT` para OWNER/ADMIN/PLANNER
autorizados. La UI exige una decisión por operación y el backend exige `futureConsent: "draft"` antes
de crear planificación futura. EMPLOYEE conserva únicamente su importación histórica SELF.
