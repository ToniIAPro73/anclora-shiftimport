## P5.4 supersession note

The previous dedicated Employee IA (`Hoy` / `Semana` / `Solicitudes` / `Más`, bottom navigation and
`PortalShell`) is superseded as the primary architecture by the shared role-aware Application Shell.
The capability contract, SELF isolation and existing domain flows are preserved; only the shell and
entry points are unified. The legacy portal components remain unused presentation code and are not a
second runtime navigation.
