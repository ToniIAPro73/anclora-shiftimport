## 1. Objectives & Scope Delivered

1. **Asignaciones Tab (Tab 4 in `EquipoModal.tsx`)**:
   - Integrated top sub-tabs:
     - `subtab-employees-to-area`: Empleados → Área (Cambio masivo).
     - `subtab-planner-scopes`: Planificadores → Ámbitos.
   - Inter-tab navigation: Clicking "Gestionar asignaciones" on any row in Tab 3 (Áreas) navigates straight to Tab 4 with that area preselected in `bulkTargetAreaId`.

2. **Bulk Move Employees to Area (`subtab-employees-to-area`)**:
   - **Target Area Selector** (`data-testid="bulk-target-area-select"`):
     - Displays all active/effective areas + "Sin área / Desasignar" (`__NONE__`).
   - **Effective Date Picker** (`data-testid="bulk-effective-date-input"`):
     - Defaults to today (ISO `YYYY-MM-DD`), allowing historical or future-dated assignments.
   - **Action Button** (`data-testid="apply-bulk-move-button"`):
     - Dynamic button label with selection count ("Aplicar a N empleados"), disabled when 0 selected or no target area chosen.
     - Calls `bulkMoveRemoteEmployeesArea({ employeeIds, targetAreaId, effectiveDate })`.
     - Displays formatted success message (`data-testid="bulk-success-message"`) with confirmation of count, area name, and effective date.
   - **Filtering & Search**:
     - Search input (`data-testid="bulk-employee-search"`) filtering by name and external employee ID.
     - Current area filter (`data-testid="bulk-filter-current-area"`) with options: "Todas", "Sin área", and specific areas.
     - Dynamic selection counter (`data-testid="bulk-selection-count"`): "X de Y seleccionados".
     - Select/Deselect All toggle (`data-testid="bulk-select-all-button"`).
   - **Employee Selection Table** (`data-testid="bulk-employees-table"`):
     - Row checkboxes (`data-testid="select-emp-${emp.id}"`), highlight on selection, employee name, external ID, current area badge, and status.

3. **Planner Scope Management (`subtab-planner-scopes`)**:
   - Planner selection dropdown (`data-testid="tab4-planner-select"`) listing all `PLANNER` and `ADMIN` members.
   - Radio buttons for 3 scope modes:
     - `ORGANIZATION` (`data-testid="tab4-scope-org"`)
     - `AREAS` (`data-testid="tab4-scope-areas"`) with multi-select area checkboxes (`data-testid="tab4-scope-area-${a.id}"`)
     - `EMPLOYEES` (`data-testid="tab4-scope-employees"`) with search input (`data-testid="tab4-scope-employee-search"`), counter (`data-testid="tab4-scope-employees-count"`), and multi-select checkboxes (`data-testid="tab4-scope-employee-${emp.id}"`)
   - Save button (`data-testid="save-tab4-planner-scope-button"`) invoking `updateRemoteMemberRole` and displaying success alert (`data-testid="tab4-planner-success"`).

4. **Integration & Error Handling**:
   - Calls `onChanged()` and refetches remote members/areas after bulk assignment or scope change.
   - Graceful error banners on API failure.
