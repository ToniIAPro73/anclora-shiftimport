# P5.2 — Role × Capability × Scope × Endpoint Matrix

Este artefacto es la salida ejecutable/documental de P5.2. Los tests de
autorización y `api/_lib/data.test.js` verifican las fronteras HTTP; el smoke
de navegador observa únicamente los journeys que necesitan UI real.

| Capacidad | OWNER | ADMIN | PLANNER | EMPLOYEE |
|---|---|---|---|---|
| Importar propios pasado/presente | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF si tiene Employee activo, según scope vigente | SELF; solo Employee propio activo |
| Importar equipo | ORGANIZATION | ORGANIZATION | No se concede capacidad multiempleado global | No |
| Añadir turno histórico propio | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF |
| Añadir turnos históricos ajenos | ORGANIZATION | ORGANIZATION | AREA | No |
| Planificar hoy/futuro | ORGANIZATION | ORGANIZATION | AREA o ORGANIZATION solo si no hay áreas activas | No |
| Publicar planificación | ORGANIZATION | ORGANIZATION | AREA o ORGANIZATION solo si no hay áreas activas | No |
| Ver calendario publicado propio | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF |
| Solicitar cambio | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF si tiene Employee activo | SELF |
| Aprobar | Según `ApprovalPolicy` | Según `ApprovalPolicy` | No en el endpoint vigente (`403`) | No |

## Fronteras verificadas

| Dominio | UI | Endpoint / servicio | HTTP esperado fuera de scope |
|---|---|---|---|
| Importación histórica | Import modal | `PATCH /api/shifts` → `upsertShifts` | `403` / `SCOPE_FORBIDDEN` |
| Alta manual histórica | Shift modal | `PATCH /api/shifts` con `origin=MAN` | `400` / `MANUAL_SHIFT_HISTORICAL_ONLY` si `date >= today` |
| Planificación | Planner modal | `POST/PATCH /api/schedules/.../assignments` | `400` / `PAST_PLANNING_FORBIDDEN` o `403` |
| Scope de Planner | Planner UI | `GET/POST /api/schedules` | `403` / `SCOPE_UNAVAILABLE` o `SCOPE_FORBIDDEN` |
| Aprobaciones | Sidebar → ModalShell | `/api/approval-requests` | `403` para roles sin capacidad |

`today` es la fecha operacional de `Europe/Madrid`, centralizada en
`src/lib/operational-date.ts` y `api/_lib/operational-date.js`. User y Employee
siguen siendo entidades distintas; tener un rol elevado no crea una identidad
operativa.
