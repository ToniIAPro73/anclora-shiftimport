## 1. Objectives & Scope Delivered

1. **Strict Desktop Viewport Contract (1440×900 Baseline)**:
   - `EquipoModal` mounts inside `ModalShell` with `workspace: true` mode:
     - Fixed shell height sized to viewport (`height: min(86vh, 920px)`), `overflow: hidden`.
     - Fixed header and tabs at top; fixed footer when present.
     - Internal scrolling strictly contained inside `.equipo-modal__table-container` (`overflow-y: auto; overflow-x: auto; flex: 1`).
     - Removed artificial `min-height: 540px` and `max-height: 80vh` constraints that could produce double scrollbars on smaller viewports.
     - Zero global window scrollbar when modal is open.
     - Zero double scrollbars across all 4 tabs.

2. **Mobile & Responsive Viewport Contract (Down to 360px)**:
   - Added responsive `@media (max-width: 768px)` rules:
     - Toolbar and filters stack vertically (`flex-direction: column`, `align-items: stretch`).
     - Search and select inputs expand to full width (`width: 100%`).
     - Tabs scroll horizontally with clean touch behavior (`overflow-x: auto`, `white-space: nowrap`).
     - Table maintains internal horizontal scroll without breaking viewport geometry.

3. **Theme Parity & WCAG AA Contrast**:
   - Comprehensive dark mode styles in `src/components/team/EquipoModal.css`:
     - Explicit bindings to application theme variables (`--color-bg-elevated`, `--toolbar-bg`, `--glass-border`, `--table-head-bg`, `--text-primary`, `--text-muted`).
     - High-contrast role badges (`--owner`, `--admin`, `--planner`, `--employee`, `--success`, `--warning`, `--neutral`) designed for both dark and light modes meeting WCAG AA contrast standards.
     - Styled danger actions and ownership transfer warning card for dark mode with amber contrast.
     - Table rows hover with `--shift-badge-hover-bg` preventing color clashes.
     - Seamless theme transitions with zero unstyled flashes.

4. **Accessibility (A11y)**:
   - Proper ARIA semantics across all tabs and subtabs:
     - `role="tablist"` on main tabs and Tab 4 subtabs.
     - `role="tab"` and `aria-selected` on active tabs.
     - `aria-label` on all filter selects and search inputs.
     - `role="alert"` on error banners; `role="note"` on warnings.
     - Modal focus trap and ESC key closing managed cleanly by `ModalShell`.
