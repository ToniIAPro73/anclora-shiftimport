## 1. Objectives & Scope Delivered
1. **Three Capability Navigation Groups**:
   - **OPERACIÓN**:
     - `Calendario` (primary calendar view, active section tracking)
     - `Planificar` (accessible to OWNER / ADMIN / PLANNER)
     - `Importar turnos` (management) / `Importar mis turnos` (employee)
     - `Añadir turno` (management) / `Añadir turno pasado` (employee)
     - `Solicitudes` ("Solicitudes" / "Solicitudes pendientes")
   - **GESTIÓN**:
     - `Equipo` (unified entry point replacing separate users/areas modals via `onTeam`, with backward-compatible fallback for `onMembers` / `onAreas`)
     - `Historial de importaciones` (repositioned into Gestión from Operación)
     - `Formatos aprendidos`
   - **CONFIGURACIÓN**:
     - `Ajustes` (separated into dedicated group)

2. **EMPLOYEE Sidebar Strict Contract**:
   - Contains strictly 4 items:
     - `Calendario`
     - `Importar mis turnos`
     - `Añadir turno pasado`
     - `Solicitudes` ("Tus solicitudes")
   - Hides: `Equipo`, `Áreas`, `Planificar`, `Historial de importaciones`, `Formatos aprendidos`, `Ajustes`.

3. **Terminology Alignment**:
   - Eliminated user-facing "Aprobaciones" from navigation in favor of "Solicitudes" / "Solicitudes pendientes".
   - Maintained full i18n parity across ES and EN with strict structural parity tested via `i18n-coverage.test.ts`.

4. **CalendarToolbar Integration**:
   - Verified toolbar with month navigation, shift counter, area and employee selectors, and manual refresh button.
