# PD-2026-09-06-P5.3-01 — OWNER no requiere ADMIN

## Metadatos

- Estado: Aprobada.
- Fecha de aprobación: 2026-09-06.
- Nivel: Product Decision (PD) local.
- Alcance: onboarding inicial y contrato de configuración completa.

## Contexto

La ausencia de un ADMIN adicional se estaba confundiendo con una configuración incompleta.

## Decisión

Una organización válida puede tener exactamente un OWNER y cero ADMIN. El OWNER puede usar las
capacidades administrativas que le corresponden sin crear otro usuario.

## Alternativas consideradas

- Exigir un ADMIN inicial: no adoptada; no aporta seguridad ni valor al caso de propietario único.
- Crear un ADMIN implícito: no adoptada; rompería la separación de identidades y roles.

## Restricciones

La configuración completa sólo exige organización válida, plan válido y al menos un OWNER.
Employee, ADMIN, áreas, turnos e histórico son opcionales.
